Today, many customers who work with unsupported banks, fintechs, payment platforms, or custom financial systems still rely on manual statement uploads to get data into Xero. We’re changing that by expanding the Xero Bank Feeds API so vetted partners can send non-bank statement data into Xero using the existing feeds flow. This capability is still currently in beta.
